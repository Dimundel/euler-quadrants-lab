# Лабораторные по уравнениям гидродинамики

- [Работа 1](notebooks/lab11.ipynb): тема 11, The Well: Euler Multi-quadrants.
- [Работа 2](notebooks/lab2.ipynb): вариант 2–1–2, интервенция в модель Навье — Стокса.

## Работа 1

В работе рассчитывается движение идеального газа методом конечных объёмов
с потоком Русанова. Для сравнения используются два источника:

- **The Well:** готовая численная траектория. По ней подбирается γ двумя
  способами: из уравнения состояния и по первым двум ненулевым кадрам.
  Затем расчёт сравнивается с более поздними кадрами.
- **ANU:** начальные условия двух задач Римана. Для каждой сравниваются
  результаты на сетках 32×32, 64×64 и 128×128.

Из уравнения состояния получается γ ≈ 1.4, а при подборе по движению —
γ ≈ 1.1185. Во втором случае относительная L2-ошибка плотности на поздних
кадрах снижается с 22.49% до 19.62%. Это настройка приближённого расчёта:
истинное γ исходного газа остаётся равным 1.4.

## Работа 2

Модель и граф взяты из [работы Ивана](https://github.com/papayiv/NavieStocks_project).
Проверяем, можно ли убрать давление, если остальные коэффициенты подобрать
заново. Вариант: ковариации параметров и риманова геометрия, зануление,
KL-дивергенция.

Есть точный синтетический пример Тейлора — Грина и внешние данные течения
за цилиндром. После зануления давления на внешних данных ошибка ускорения
растёт с 0.26% до 45.27%. В синтетике ошибка почти не меняется, зато
коэффициент конвекции переходит от 1 к 0. В обоих случаях ветви давления
сохраняем.

Перед вычислением производных убран исходный кадр t=0: он смещал первую
оконную оценку и сильно влиял на ковариацию. В ноутбуке есть сравнение
с прежней обработкой; решение о давлении остаётся тем же.

Дополнительно сравниваем МНК и функцию Хьюбера на тех же временных
окнах: распределения коэффициентов, KL и ошибку на проверочных кадрах.
Оба способа дают решение сохранить давление.

[Ноутбук с расчётами](notebooks/lab2.ipynb),
[короткая презентация](results/lab2/lab2_slides.pptx).
В заметках к слайдам есть текст для выступления.

Это черновик к обсуждению. Внешние данные тоже получены численно, поэтому
нужно уточнить, подходят ли они под пункт «реальные данные».

## Запуск

Нужен `uv`. Из папки проекта:

```bash
uv sync --locked
uv run --locked jupyter lab notebooks/lab11.ipynb
```

`uv` создаст окружение с Python 3.12 и установит зависимости из `uv.lock`.
В VS Code можно открыть тот же ноутбук и выбрать ядро из `.venv`.

Чтобы пересчитать весь ноутбук без открытия Jupyter:

```bash
uv run --locked python scripts/run_lab.py
```

Вторая работа:

```bash
uv run --locked jupyter lab notebooks/lab2.ipynb
uv run --locked python scripts/run_lab2.py
```

Тесты:

```bash
uv run --locked pytest -q
```

Данные уже лежат в репозитории, для расчёта интернет не нужен.
При необходимости их можно скачать заново:

```bash
uv run --locked python scripts/download_data.py
uv run --locked python scripts/download_lab2_data.py
```

## Данные

[The Well](https://polymathic-ai.org/the_well/datasets/euler_multi_quadrants_openBC/)
— результаты численного моделирования Clawpack, авторы Ohana et al.,
лицензия CC-BY-4.0. Взяты семь кадров одной траектории, сетка усреднена
с 512×512 до 64×64.

Из [ANU / Fyris](https://www.mso.anu.edu.au/fyris/lw2driemann.html) взяты
начальные условия случаев 3 и 6 Лиски — Вендроффа. Последующее течение
рассчитывается нашим солвером. Сетка 128×128 служит для сравнения с более
грубыми сетками; это тоже приближённое решение.

Данные и эксперименты здесь двумерные, хотя в общем задании указано 3D+t.
Солвер поддерживает три направления, но в расчёте The Well слои по z
одинаковы и скорость вдоль z равна нулю.

Подробности выборки, времени и сетки — в [манифесте](data/processed/sources.json).
Ссылки на статьи приведены в ноутбуке.

Для второй работы взяты поля скорости и давления из
[открытых материалов Raissi et al.](https://maziarraissi.github.io/PINNs/).
У Ивана в файле PDEBench давления нет, поэтому для этой интервенции выбран
другой набор той же системы. Сохранены все 200 кадров на сетке 100×50.
Версии источников и SHA-256 — в [манифесте второй работы](data/processed/lab2_sources.json).
Обе постановки второй работы также двумерные.
