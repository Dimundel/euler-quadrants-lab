# Задачи Римана для уравнений Эйлера

Лабораторная работа 1, тема 11 — The Well: Euler Multi-quadrants.

Все расчёты, графики и выводы — в [ноутбуке](notebooks/lab11.ipynb).

В работе рассчитывается движение идеального газа методом конечных объёмов
с потоком Русанова. Для сравнения используются два источника:

- **The Well:** готовая численная траектория. По ней подбирается γ двумя
  способами: из уравнения состояния и по первым двум ненулевым кадрам.
  Затем расчёт сравнивается с более поздними кадрами.
- **ANU:** начальные условия двух задач Римана. Для каждой сравниваются
  результаты на сетках 32×32, 64×64 и 128×128.

Из уравнения состояния получается γ ≈ 1.4, а при подборе по движению —
γ ≈ 1.1185. Во втором случае относительная L2-ошибка плотности на поздних
кадрах снижается с 22.49% до 19.62%. Это настройка приближённого расчёта:
истинное γ исходного газа остаётся равным 1.4.

## Запуск

Нужен `uv`. Из папки проекта:

```bash
uv sync --locked
uv run --locked jupyter lab notebooks/lab11.ipynb
```

`uv` создаст окружение с Python 3.12 и установит зависимости из `uv.lock`.
В VS Code можно открыть тот же ноутбук и выбрать ядро из `.venv`.

Чтобы пересчитать весь ноутбук без открытия Jupyter:

```bash
uv run --locked python scripts/run_lab.py
```

Данные уже лежат в репозитории, для расчёта интернет не нужен.
При необходимости их можно скачать заново:

```bash
uv run --locked python scripts/download_data.py
```

## Что где лежит

- `src/euler_lab/` — солвер, подбор γ, загрузка данных и графики.
- `data/processed/` — сохранённая выборка и сведения об источниках.
- `results/` — рисунки и метрики последнего расчёта.

## Данные

[The Well](https://polymathic-ai.org/the_well/datasets/euler_multi_quadrants_openBC/)
— результаты численного моделирования Clawpack, авторы Ohana et al.,
лицензия CC-BY-4.0. Взяты семь кадров одной траектории, сетка усреднена
с 512×512 до 64×64.

Из [ANU / Fyris](https://www.mso.anu.edu.au/fyris/lw2driemann.html) взяты
начальные условия случаев 3 и 6 Лиски — Вендроффа. Последующее течение
рассчитывается нашим солвером. Сетка 128×128 служит для сравнения с более
грубыми сетками; это тоже приближённое решение.

Данные и эксперименты здесь двумерные, хотя в общем задании указано 3D+t.
Солвер поддерживает три направления, но в расчёте The Well слои по z
одинаковы и скорость вдоль z равна нулю.

Подробности выборки, времени и сетки — в [манифесте](data/processed/sources.json).
