# Задачи Римана для уравнений Эйлера

Лабораторная работа 1, тема 11: **The Well: Euler Multi-quadrants**.

Исследуется, как схема конечных объёмов воспроизводит движение идеального
газа с разрывными начальными условиями. Расчёты и графики будут собраны
в ноутбуке, повторно используемый код — в `src/euler_lab`.

Постановка включает загрузку открытых данных по HTTPS, представление
уравнений графом, подбор параметра, сравнение с данными и проверку солвера.
The Well содержит двумерные поля; их продолжение вдоль третьей оси
рассматривается явно как частный случай трёхмерных уравнений.
