# Задачи Римана для уравнений Эйлера

Лабораторная работа 1, **тема 11 — The Well: Euler Multi-quadrants**.

Основная работа — [выполненный ноутбук](notebooks/lab11.ipynb).
Для просмотра без Jupyter можно скачать и открыть [HTML-версию](results/lab11.html).
Для подготовки к защите — [подробный конспект на вечер](docs/STUDY_GUIDE.md):
теория, разбор кода и графиков, вопросы преподавателя и самопроверка.

Решается задача движения идеального газа с разрывными начальными условиями
схемой конечных объёмов с потоком Русанова. Показатель адиабаты подбирается
по уравнению состояния и по ранним кадрам движения. Затем решение сравнивается
с поздними кадрами.

## Что получилось

- Из полей The Well восстановлено γ ≈ **1.400000**; ожидалось 1.4.
- Подбор по ранней динамике дал γ ≈ **1.1185**. Он частично компенсирует
  численное сглаживание и не является оценкой истинного параметра газа.
- На поздних кадрах ошибка плотности составляет **22.49%** при γ из уравнения
  состояния и **19.62%** после подбора по динамике, в относительной L2-норме.
- На начальных условиях ANU сравнение сеток 32² и 64² с расчётом на 128²
  показывает уменьшение расхождения плотности с **9.11% до 4.30%**
  для случая 3 и с **8.97% до 4.03%** для случая 6.

Схема первого порядка заметно сглаживает ударные фронты. Все ошибки показаны
в ноутбуке; высокая точность на всём датасете не заявляется.

## Запуск

Для сохранённого набора версий нужен Python 3.12. На нём выполнен расчёт.
Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e . --no-deps
python -m pytest -q
python scripts/run_lab.py
```

В Windows окружение активируется командой `.venv\Scripts\activate`.
Повторный запуск использует сохранённые данные и обновляет ноутбук,
`results/lab11.html`, графики и `results/metrics.json`.
В вычислениях сеть не требуется; HTML использует MathJax для формул.
Ноутбук также можно открыть в Jupyter или VS Code с этим Python-окружением.

Для повторной загрузки исходных данных по HTTPS:

```bash
python scripts/download_data.py
```

Загрузчик получает около **58 MB** диапазонами байтов, а не весь HDF5 на 5.3 GB.
Он отказывается от полного HTTP-ответа и ограничивает трафик 100 MB.
В репозитории сохранён обработанный фрагмент размером около 172 KB.
URL, версия источника, выборка и контрольные суммы — в
[манифесте данных](data/processed/sources.json).

## Источники и ограничения

Данные взяты из двух независимых источников:

1. [Polymathic AI / The Well](https://polymathic-ai.org/the_well/datasets/euler_multi_quadrants_openBC/):
   численное решение Clawpack, одна траектория и семь кадров. Данные CC-BY-4.0,
   авторство — Ohana et al.; применены выборка кадров и усреднение.
2. [ANU / Fyris](https://www.mso.anu.edu.au/fyris/lw2driemann.html):
   опубликованные начальные условия тестов Лиски — Вендроффа.
   Чужие код и изображения не включены.

Журнальная основа: [Lax–Liu, 1998](https://doi.org/10.1137/S1064827595291819)
и [Liska–Wendroff, 2003](https://doi.org/10.1137/S1064827502402120).
Полная библиография приведена в ноутбуке.

**О размерности.** Внешние данные этой темы — 2D+t, хотя общие требования
говорят о 3D+t. Солвер учитывает три пространственных направления, а плоские
данные The Well продолжены одинаковыми слоями вдоль z при w=0.
Все эксперименты в ноутбуке описывают двумерное течение.
Независимых внешних 3D-данных в работе нет. Если требуются именно такие данные,
плоское продолжение нужно отдельно согласовать с преподавателем.

В выбранном HDF5 время хранится индексами. Используется интервал 0.015
из карточки данных; сетка решателя соответствует области [0,1] из описания.
Неоднозначности метаданных описаны в ноутбуке и манифесте. Сетка ANU 128²
служит проверкой согласованности, а не точным решением.
