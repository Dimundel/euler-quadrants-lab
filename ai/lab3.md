## Принятые решения

Выбираем, какие из девяти групп слагаемых модели Ивана оставить в уравнении.
У каждой группы есть коэффициент включения от 0 до 1. Веса слагаемых
подбираем с регуляризацией. Затем строим бинарные маски. Результаты
условного перемешивания влияют на следующий шаг поиска.

Веса модели и пороги диагностики оцениваем на обучении. Маску выбираем
на валидации. На тесте измеряем ошибку уже выбранной модели.
Отдельно перебираем все 512 масок, чтобы проверить качество поиска.

В `results/lab3/` сохраняем маски, ход оптимизации, значения диагностики,
ошибки и графики.

## Ограничения постановки

Перемешивание меняет входы модели при прежнем отклике. Так проверяем
чувствительность расчёта. Для вывода о физических причинах нужны другие
данные и предположения. Бутстреп показывает разброс MAP-оценок при повторной
выборке блоков. Порог сдвига оцениваем по случайным половинам блоков;
частота ложных решений для этого порога не гарантирована.

The Well содержит результаты численного расчёта. Все три набора двумерные,
поэтому по ним нельзя судить о необходимости ветви z в объёмном течении.
Проверяем точность производных; длительное решение по выбранному уравнению
здесь не рассчитывается.

## Проверка и завершение

При проверке контрольного солвера выяснилось, что изменённый закон давления
требует другой скорости волн. Для него написан отдельный модуль. Формула
проверена по якобиану потока, результаты контроля пересчитаны. Код Ивана
сохранён без изменений.

Тесты проверяют влияние диагностики на поиск и разделение данных:
тестовый кадр не должен влиять на обучение. Повторный расчёт подтвердил
коэффициенты и ошибки всех 12 выбранных моделей, значения диагностики
и 2197 записей архива.

По запросу «проверь третью лабу. и упрости текст везде убери тире и ИИ-слоп»
сокращены объяснения в ноутбуке, README и тексте выступления. Уточнены
подписи графиков. В проверке участвовали OpenAI Codex и отдельные агенты
для проверки математики, результатов и редактирования текста.

При сверке с презентацией уточнён вывод о The Well. Полный перебор
с интервенционным штрафом и без него выбирает одну маску из пяти групп.
Поиск без штрафа сохранил шесть групп, не достигнув своего минимума,
и дал меньшую тестовую ошибку. В отчёте разделены сравнение этих запусков
и вывод о влиянии самого штрафа.
