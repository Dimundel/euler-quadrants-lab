# Использование ИИ

Для этой лабы я использовал OpenAI Codex. С его помощью подготовлены код
солвера, загрузка данных, подбор γ, тесты и ноутбук с графиками и выводами.
С ним же разбирал метод конечных объёмов, поток Русанова и разницу между
двумя способами подбора γ.

Данные взяты из The Well и ANU. Числа в отчёте получены выполнением кода;
готовое решение The Well используется для сравнения с нашим расчётом.
Тесты проверяют отдельные свойства программы. Их можно запустить так:

```bash
uv run --locked pytest -q
```

## Что было в контексте

В начале передал PDF с требованиями и уточнил, что нужна тема 11 —
The Well: Euler Multi-quadrants, лабораторная работа 1. Дальше в работе
использовались код проекта, описание источников и результаты запусков.

Основные договорённости: функции вынести из ноутбука, использовать NumPy,
SciPy и NetworkX, отдельно показать подбор γ из уравнения состояния и по
ранним кадрам. Поздние кадры оставить для проверки. Размерность данных
и допущения о времени указать в отчёте.

[Основные запросы](prompts.md) собраны отдельно. Для чтения методички
использовался навык PDF; [копия его инструкций](pdf-skill.md) тоже сохранена.
