# Запросы к ИИ

Здесь собраны основные запросы по работе. Технические формулировки
сокращены и сгруппированы по смыслу; это не полная переписка.

## Постановка

Сделать лабораторную по теме 11 — The Well Euler Multi-quadrants,
оформить её в приватном репозитории, сохранять этапы отдельными коммитами.
Коммиты писать на английском. Требования переданы в PDF.

## Данные

Найти описание The Well и второй источник для задач Римана. Загрузить
небольшой фрагмент The Well, сохранить источники и преобразования данных.
Для сравнения взять начальные условия ANU. Проверить размерность полей,
временную ось и усреднение сетки.

## Расчёт

Реализовать метод конечных объёмов с потоком Русанова. Вынести функции
в отдельные модули. Добавить шаг времени по CFL и проверки некорректных
состояний. Построить граф зависимостей уравнений.

Сначала подобрать γ по уравнению состояния. Затем отдельно подобрать его
по двум ранним кадрам движения. Для каждого кандидата запускать солвер,
сравнивать плотность и давление. Поздние кадры использовать для проверки.

## Ноутбук и проверка

Собрать постановку, формулы, данные, расчёты, графики и выводы в ноутбуке.
На начальных условиях ANU сравнить несколько сеток. Добавить тесты солвера,
подбора параметра и обработки данных, выполнить ноутбук и проверить результаты.

## Разбор работы

В переписке отдельно разбирались: физический смысл γ, два способа его подбора,
функция ошибки и метод Брента, условие CFL, поток через грани ячеек,
отличие исходных данных от нашего решения и смысл каждого графика.

Для запуска настроить uv. Отчёт оставить в формате Jupyter Notebook,
README написать коротко: что сделано и как запустить.
