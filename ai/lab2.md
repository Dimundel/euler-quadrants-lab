# Помощь ИИ во второй работе

Для второй лабы я продолжил работу с OpenAI Codex. Передал PDF с новым
заданием, переписку с распределением вариантов и напомнил ссылку на работу
Ивана. Мой вариант — 2–1–2, модель меняем в паре Дмитрий — Иван.

Начальные запросы были такими:

> теперь делаем лабу номер 2

> и репу Ивана я вроде кидал ссылку тебе когда просил сравнить)

В контексте оставались требования использовать uv, английские сообщения
коммитов, вынести функции из ноутбука и сохранить тесты и сведения об ИИ.

Codex прочитал задание и код `papayiv/NavieStocks_project`, предложил
занулить давление и сравнить распределения оценок коэффициента конвекции
и вязкости. Исходный граф Ивана скопирован без изменений из коммита
`66eb7bc73cd802a3249c058ad69fc59a95fbd807`. Новый анализ написан отдельно.
В исходной работе нет наблюдаемого давления, поэтому взяты открытые
данные Nektar++ из материалов Raissi et al. Этот выбор явно описан
в ноутбуке, численные данные не названы физическими измерениями.

С помощью Codex подготовлены МНК, ковариации по временным блокам,
KL для гауссовых распределений, геодезическая ковариаций, тесты,
ноутбук и презентация. Все числа в отчёте получены выполнением кода.
В заметках слайдов есть черновик устного рассказа. Вопросы о внешних
данных, геометрии и смысле интервенции оставлены для обсуждения с преподавателем.

Для PDF использовался [навык PDF](pdf-skill-lab2.md), для слайдов —
[Presentations](presentation-skill.md). Это копии инструкций инструментов.
Код первой работы и её результаты при подготовке второй не менялись.

## Проверка и исправления 22 октября

Попросил Codex проверить готовую работу по заданию, затем исправить
найденное и писать пояснения обычным студенческим языком. При проверке
нашлось влияние начального кадра внешнего набора на первую оконную
оценку. Добавили явное исключение этого кадра перед производными,
проверку чувствительности и тесты. Ноутбук, числа и слайды пересчитаны.
Вопрос о том, подходят ли внешние численные данные под требование
«реальных данных», оставлен для преподавателя.

## Сравнение функций ошибки 29 октября

Попросил сравнить работу с примерами одногруппников. При проверке задания
обнаружили, что в ноутбуке не было сравнения функций ошибки. С помощью
Codex добавили функцию Хьюбера, графики распределений и сравнение с МНК
на тех же данных и временных окнах. Масштаб невязок определяем по исходной
обучающей части и сохраняем при интервенции. Внешний набор оставили прежним:
преподаватель пока не уточнил, что именно понимается под реальными данными.
